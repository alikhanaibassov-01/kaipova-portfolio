# Каипова Айнур Абдиханқызы — визитка педагога и ЦОР по ПМ 02

Статический сайт (HTML + CSS + немного JS, без сборки) для **Каиповой А.А.**, мастера производственного обучения и педагога-эксперта КГКП «Колледж принтмедиа технологий» (г. Алматы).

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Визитка-портфолио педагога: о педагоге, компетенции, авторская программа, контакты, карта 2ГИС |
| `cor.html` | ЦОР по учебному модулю ПМ 02 «Воспроизведение изобразительной информации»: цель и задачи, три раздела программы, результаты обучения, критерии оценивания |
| `style.css` | Общие стили обеих страниц |
| `script.js` | Аккордеон разделов программы |
| `assets/` | Фото педагога и логотип колледжа |

## Локальный запуск

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Что можно поправить

- **Контакты** — раздел «Контакты» в `index.html` (email пока указан как образец).
- **Ширина контента и масштаб текста** — переменная `--wrap` и `html { font-size }` в начале `style.css`.
- **Карта** — виджет 2ГИС, адрес: г. Алматы, ул. Шевченко, 202.
